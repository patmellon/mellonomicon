# The Mellonomicon

Minimal static personal landing page for Pat Mellon, built with React, TypeScript, and Vite.

## Local development

```bash
nvm use
npm install
npm run dev
```

## Build

```bash
nvm use
npm run build
npm run preview
```

## Deployment

Vercel can build the site with `npm run build` and publish the `dist` output directory via [vercel.json](/Users/patmellon/Desktop/workspace/mellonomicon/vercel.json).

## Portrait

Place the portrait image at `public/pat-portrait.jpg`. If that file is missing, the page renders a simple placeholder instead.
